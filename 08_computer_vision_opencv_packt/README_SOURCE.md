# Learning OpenCV 4 Computer Vision with Python, Third Edition

Fonte: https://github.com/PacktPublishing/Learning-OpenCV-4-Computer-Vision-with-Python-Third-Edition

Esta pasta reúne scripts de visão computacional selecionados do repositório público da Packt, mantendo a estrutura por capítulos quando aplicável. O objetivo é complementar a biblioteca com exemplos práticos de OpenCV para processamento de imagens, detecção, reconhecimento, features, rastreamento, fluxo óptico e redes neurais/DNNs.
