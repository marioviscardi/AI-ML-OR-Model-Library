# AI-ML-OR-Model-Library

Biblioteca de referência com implementações didáticas em Python e R para IA, Machine Learning, Pesquisa Operacional, metaheurísticas e otimização.

## Conteúdo atual

Total de scripts: **133**

- Redes neurais, CNNs e modelos de linguagem
- Machine Learning supervisionado
- Aprendizado não supervisionado
- Pesquisa Operacional
- Metaheurísticas
- Otimização de redes neurais
- Implementações em R
- Exemplos adicionais de visão computacional em OpenCV

## Instalação

```bash
pip install -r requirements.txt
```

Os scripts são pequenos e independentes para facilitar estudo, comparação, reutilização e indexação por RAG.

Consulte `REFERENCES.md` e preserve as licenças ao incorporar código de terceiros.

## OpenCV / Packt

Foi adicionada a pasta `08_computer_vision_opencv_packt/` com exemplos práticos selecionados do repositório público **Learning OpenCV 4 Computer Vision with Python, Third Edition**, da Packt Publishing.

A coleção adicionada inclui Canny, Hough Lines, Hough Circles, GrabCut, Watershed, ORB, SIFT, homografia com FLANN, HOG para detecção de pessoas, detecção de movimento, fluxo óptico Lucas-Kanade, filtro de Kalman e ANN/MLP do OpenCV.

O material de origem está sob licença BSD 3-Clause, preservada em `08_computer_vision_opencv_packt/LICENSE_PACKT_BSD_3_CLAUSE.txt`.
