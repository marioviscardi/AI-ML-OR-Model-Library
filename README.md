# AI-ML-OR-Model-Library

Biblioteca prática de referência com implementações didáticas em Python e R para:
- Redes neurais e visão computacional
- Modelos de linguagem e Transformers
- Machine Learning supervisionado
- Aprendizado não supervisionado
- Pesquisa Operacional
- Metaheurísticas
- Otimização aplicada a redes neurais

## Estrutura

- `01_neural_networks/`
- `02_supervised_machine_learning/`
- `03_unsupervised_learning/`
- `04_operations_research/`
- `05_metaheuristics/`
- `06_optimization_for_neural_networks/`
- `07_R_implementations/`
- `REFERENCES.md`

## Objetivo

Servir como base de exemplos concretos para estudo, experimentação e recuperação via RAG/IA local.

## Uso

Crie um ambiente virtual e instale:

```bash
pip install -r requirements.txt
```

Os scripts são intencionalmente curtos e independentes para facilitar indexação, comparação entre métodos e reutilização.

## Observação de licenças

Os scripts deste repositório foram redigidos como exemplos didáticos originais. O arquivo `REFERENCES.md` lista projetos públicos usados como referências conceituais e de API. Ao copiar código de terceiros para este repositório, preserve a licença e os avisos de copyright do projeto de origem.
